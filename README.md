# 호야 韓語

給**完全沒學過韓文**的人的韓文練習網頁：從 40 音、拼音組字、收音開始，再用生活主題練單字、聽力和口說。介面是繁體中文。

## 內容

- **基礎發音**：基本母音、母音聽辨特訓（嘴型圖、母音位置圖、ㅓ/ㅗ・ㅡ/ㅜ 等對比單字、錄自己的聲音比較）、基本子音（發音側面圖、字形由來）、硬音與「平音・送氣音・硬音」比較、子音聽辨特訓（달／탈／딸 等對比單字）、複合母音、組字規則、收音（받침）、6 個發音規則
- **生活主題**：打招呼、自我介紹、數字與價錢、咖啡廳點餐、逛街購物、交通與問路
- **工具**：40 音表、拼音工坊（自己組字、看結構、聽發音）、子音與母音發音地圖（點字母看嘴巴裡怎麼動的動畫，對照注音與口訣）
- **練習**：每課的小測驗、跟讀評分（麥克風）、念給 App 聽（告訴你被聽成哪個字、該怎麼改）、單字間隔複習（1→3→7→14→30 天）、單字本
- **遊戲**：聽音辨字、聽音組字、字母配對、單字快問快答、句子排列
- **獎勵**：上課、遊戲、複習、每日任務、簽到、連續天數都能賺點數（₩），在商店買介面風格和小老虎호야的服裝、背景
- **設定**：6 種介面風格（2 種免費）、羅馬拼音顯示／點了才看／隱藏、實際發音 [ ]、語速、韓文聲音、進度備份與匯入

羅馬拼音採用韓國官方「國語羅馬字表記法」，依實際發音自動產生（例如 감사합니다 → gamsahamnida）。

## 使用

純 HTML + CSS + JavaScript，不需要安裝。直接用瀏覽器開 `index.html`，或在資料夾裡執行 `python3 -m http.server` 再開 `http://localhost:8000`。

- 語音播放用瀏覽器內建的語音（需要韓文語音；手機可在「文字轉語音」設定加裝）。
- 跟讀評分用瀏覽器的語音辨識，Chrome／Android 最穩定。
- 進度存在這台裝置的瀏覽器（localStorage），換裝置請用「設定 → 下載備份／匯入備份」。

## 放上 GitHub Pages

repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。一兩分鐘後網址是 `https://<帳號>.github.io/korean/`。

## 測試

需要 Node 與 Playwright（`npm i -D playwright` 後 `npx playwright install chromium`）。

```bash
node tests/run-all.js
```
